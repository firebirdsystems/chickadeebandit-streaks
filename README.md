# Streaks

A [Chickadee Bandit](https://chickadeebandit.com/app-library/streaks) app.

Track personal and family habits with streak counters. Create private or shared streaks, set up group challenges anyone can check off, and celebrate milestones together.

## Features

- Private or shared streaks.
- Group challenges anyone can check off.
- Milestone celebrations.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-streaks/releases/latest/download/bundle.json
```
